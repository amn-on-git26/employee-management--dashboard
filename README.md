# Employee Management Dashboard

A responsive employee dashboard built with HTML, CSS, and JavaScript. It includes:

- Employee CRUD operations
- Search by name or email
- Department filtering
- Sorting by name and salary
- Pagination
- Dark mode
- Local storage persistence

## Run locally

Open [index.html](index.html) directly in a browser, or serve the folder with a simple static server:

```bash
python -m http.server 8000
```

Then visit http://127.0.0.1:8000/

## Upload to GitHub

git init
